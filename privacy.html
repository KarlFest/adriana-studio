POLÍTICA DE PRIVACIDAD

Privacidad y uso de datos

Última actualización: 23 de septiembre de 2026

Esta política describe cómo ADRIANA STUDIO utiliza la información a la que accede mediante su aplicación interna de analítica de Pinterest.

1. Finalidad de la aplicación

La aplicación se utiliza exclusivamente para consultar información de la cuenta de Pinterest que haya sido autenticada y autorizada por su propietario, incluyendo Pines, tableros y métricas orgánicas disponibles mediante la API de Pinterest.

2. Datos utilizados

Dependiendo de los permisos concedidos, la aplicación puede procesar identificadores de Pines y tableros, títulos, enlaces, fechas de publicación y métricas de rendimiento como impresiones, guardados, clics y otras métricas orgánicas ofrecidas por Pinterest.

3. Cómo se usan los datos

Los datos se utilizan para elaborar informes internos, medir el rendimiento del contenido, mantener un histórico de publicaciones y orientar decisiones editoriales y de producción de ADRIANA STUDIO.

4. Alcance del acceso

La aplicación está destinada al uso interno de ADRIANA STUDIO. No está diseñada para acceder a cuentas de Pinterest de terceros ni para ofrecer servicios de analítica a otros usuarios.

5. Compartición y venta de datos

ADRIANA STUDIO no vende los datos obtenidos mediante la API de Pinterest. La información no se comparte con terceros salvo cuando sea necesario para operar la infraestructura técnica utilizada por ADRIANA STUDIO o cuando exista una obligación legal aplicable.

6. Conservación y seguridad

Los datos pueden conservarse mientras sean necesarios para análisis histórico y operación interna. ADRIANA STUDIO procura limitar el acceso a la información y mantener controles razonables para evitar el acceso, uso o divulgación no autorizados.

7. Revocación del acceso

El propietario de la cuenta puede revocar la autorización concedida a la aplicación mediante las opciones disponibles en Pinterest. Tras la revocación, la aplicación dejará de realizar nuevas consultas autenticadas a esa cuenta.

8. Sitio web

Este sitio informativo no utiliza formularios de registro, no ofrece cuentas de usuario y no incorpora intencionalmente cookies de seguimiento propias.

9. Cambios a esta política

Esta política puede actualizarse cuando cambie la funcionalidad de la aplicación, el uso de datos o los requisitos aplicables. La fecha de actualización se mostrará en esta página.

10. Contacto

Para consultas relacionadas con esta política o con el uso de datos, puede utilizarse el repositorio público oficial de ADRIANA STUDIO en GitHub: github.com/KarlFest/adriana-studio.
